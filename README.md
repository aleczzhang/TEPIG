# TEPIG — TEnsor grouP lasso wIth clusterinG

Scalar-on-tensor regression with unbalanced, unordered object populations. Each
subject contributes a variable number of objects (cells, tubules) with feature vectors,
replicated across sections or imaging sites. TEPIG pools all objects, clusters them with
one Gaussian mixture, builds a balanced (clusters x features x sections) tensor per
subject from proportion-weighted cluster means, and fits a feature-wise group lasso with
an adaptive selection threshold. It is compared with CLUSSO (Rubin et al.) and a naive
lasso on the averaged features.

## Layout

```
tepig/                 the method (importable package)
  tepig.py             solver (FISTA group lasso), lambda grid, cross-validation,
                       grouped folds, selection threshold, run metadata
  selection_metrics.py Jaccard / Kuncheva / Nogueira stability
  clusso/              port of the CLUSSO competitor used in the comparisons
simulation/            synthetic study: simulation_synthetic.py (one setting),
                       summarize_synthetic.py (table), plot_figures.py
cell_painting/         CDRP Cell Painting application
  extract/             plate SQLite -> (G, q, S, n) tensor caches; cache merging
  screen/              all-gene ridge/lasso screens, permutation null,
                       structured-vs-averaged ridge diagnostic
  panel/               feature preselection, TEPIG/CLUSSO/naive fits per
                       gene and split, result combiner
  figures/             scripts for the panel figures
  data/                small provenance CSVs (plate samples, L1000 coverage, id map)
  genes.py, compute_log.py
slurm/                 cluster jobs (preemption-safe arrays) and extraction drivers
tests/                 test_tepig_core.py
figures/               figures used in the manuscript
requirements.txt
```

Large inputs and outputs (`cell_painting/cache|results|logs|data` downloads, `outputs/`)
are generated by the scripts and not tracked.

## Running

```
pip install -r requirements.txt
python tests/test_tepig_core.py
python simulation/simulation_synthetic.py --n 300 --q 50 --sparsity 0.8
python cell_painting/panel/run_panel.py HMGCS1 --cache cdrp_213.pkl --select pycytominer --split-by-plate --seeds 42
```

Every script resolves its paths from its own location, so it can be run from any
directory. The `slurm/` scripts submit the full study on a cluster; each array task
skips work that is already finished.
